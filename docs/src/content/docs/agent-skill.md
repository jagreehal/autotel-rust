title: Agent Skill
description: Teach your coding assistant the autotel API.
---

Install the [`autotel-rust`](https://github.com/jagreehal/autotel-rust/blob/main/skills/autotel-rust/SKILL.md) skill so your coding assistant uses the crate's API:

```sh
npx skills add jagreehal/autotel-rust --skill autotel-rust
```
